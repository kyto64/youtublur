# 製品仕様

製品の機能仕様とユーザーストーリー。

## 製品概要

**youtublur** は、YouTube視聴ページのプレイヤー背景をユーザーが選択した単色またはブラー表示に切り替えるブラウザ拡張機能です。

## 対象ユーザー

- YouTubeを長時間視聴するユーザー
- 視覚的な疲労を軽減したいユーザー
- 集中して動画視聴を行いたいユーザー
- シンプルな操作性を好むユーザー

## 主要機能

### 1. 背景モード切替

ユーザーは以下の3つのモードから選択できます：

- **デフォルト**: YouTubeの標準背景（変更なし）
- **単色**: ユーザー選択の単一カラーで背景を塗りつぶし
- **ブラー**: YouTubeの背景をブラー（ぼかし）表示

### 2. カラーカスタマイズ

- カラーピッカーを使用して単色モードの色を選択可能
- 選択した色は即座にプレビュー可能
- 設定は自動保存され、次回以降の視聴時に反映

### 3. 自動保存と同期

- 設定はブラウザ間で自動同期（Chromeの場合）
- 複数デバイスで同じ設定が反映される
- タイムスタンプベースの競合解決

### 4. スマートな背景検出

- プレイヤー要素が動的に読み込まれるのを自動検出
- ダークモード/ライトモードを自動検出して最適化
- プレイヤーの変更（フルスクリーンなど）を監視

## ユーザーストーリー

### ストーリー1: 視覚的疲労の軽減

```
ユーザーは2時間以上YouTubeを視聴する際に、
明るい背景が目に負担になるため、背景を暗い単色に変更したい。

→ 拡張機能アイコンをクリックし、
   モードを「単色」に変更し、
   暗い色を選択する。

結果: 背景が選択した色に変更され、
      視覚的な疲労が軽減される。
```

### ストーリー2: 集中力の向上

```
ユーザーは勉強や作業しながらYouTubeを視聴しており、
背景の動くサムネイルなどに気を散らされたくない。

→ 拡張機能アイコンをクリックし、
   モードを「ブラー」に変更する。

結果: 背景がブラー表示され、
      周囲の視覚的ノイズが減り、
      動画に集中できる。
```

### ストーリー3: ナイトモードでの視聴

```
ユーザーは夜間に部屋を暗くしてYouTubeを視聴しており、
画面の明るさを抑えたいが、動画自体は見たい。

→ 拡張機能アイコンをクリックし、
   モードを「単色」に変更し、
   非常に暗いグレーを選択する。

結果: 背景が暗くなり、
      全体的な画面の明るさが抑えられ、
      目にやさしい視聴が可能になる。
```

### ストーリー4: 統一された視覚体験

```
ユーザーは複数のデバイス（PC、ノートPC）でYouTubeを視聴しており、
どのデバイスでも同じ背景設定にしたい。

→ どちらかのデバイスで設定を変更する。

結果: 設定が自動的に同期され、
      すべてのデバイスで同じ背景設定が反映される。
```

## インターフェース仕様

### ポップアップUI

**レイアウト:**
```

  YouTube Background

  ┌─────────────────┐
  │      モード      │
  │  [デフォルト]    │
  │  [単色]         │
  │  [ブラー]       │
  └─────────────────┘

  ┌─────────────────┐
  │      色選択      │
  │   [カラーピッカ  │
  │    ャー]        │
  └─────────────────┘

  現在のモード: 単色
  現在の色: #333333

```

**操作フロー:**

1. ユーザーが拡張機能アイコンをクリック
2. ポップアップが開く（現在の設定が反映された状態）
3. ユーザーがモードを選択（ラジオボタン）
4. 単色を選択した場合、カラーピッカーが有効化
5. ユーザーが色を選択
6. 変更が即座にYouTubeページに反映
7. 設定が自動保存
8. ポップアップを閉じる（クリックまたは外側クリック）

### 設定値

| 設定キー | 値の型 | 説明 | デフォルト値 |
|---------|--------|------|-------------|
| `mode` | string | 背景モード (`default`, `solid`, `blur`) | `default` |
| `color` | string | 16進数カラーコード | `333333` |
| `timestamp` | number | 最終更新時刻（競合解決用） | `0` |
| `playerBlurStrengthPx` | number | ブラー半径（px）。8〜72、4px 刻み。単色モードでは使わない | `40` |
| `playerBlurStrengthPxTimestamp` | number | ブラー強度の最終更新時刻（sync / local の競合解決） | `0` |

ブラー強度はポップアップのスライダーで変える。未設定のときは 40px で、以前の固定値と同じ見え方になる。単色モードではスライダーを出さない。変更は開いている YouTube タブへ再読み込みなしで反映される。

### キーボードショートカット

ポップアップと同じ設定を、WebExtension の `commands` API で変える。保存キーは `playerBackgroundMode` と `playerBlurStrengthPx` のまま（新しいキーは増やさない）。オン/オフ専用の値は無い。モードは `blur` と `solid` の2つなので、切替コマンドがその両方を担当する。

| コマンド | 既定の割り当て | 動作 |
|---------|----------------|------|
| `toggle-mode` | Alt+Shift+Y | ブラーと単色を切り替える |
| `increase-blur-strength` | Alt+Shift+Period | ブラー強度を 4px 上げる（8–72） |
| `decrease-blur-strength` | Alt+Shift+Comma | ブラー強度を 4px 下げる（8–72） |

上限または下限のときは保存しない。開いているタブへ既存の `BG_MODE_CHANGED` / `BLUR_STRENGTH_CHANGED` を送る。URL では絞り込まない（追加権限を避ける）。YouTube 以外はコンテンツスクリプトが無いのでメッセージを無視する。ポップアップは現在の割り当てと、ブラウザのショートカット設定を開くボタンを出す。

## 非機能要件

### パフォーマンス

- コンテンツスクリプトのメモリ使用量: 5MB以内
- ポップアップの起動時間: 100ms以内
- 背景適用の応答時間: 50ms以内
- 定期的なポーリング間隔: 1秒

### 互換性

- Chrome: バージョン 121以上（Manifest V3。`background.scripts` と `service_worker` を併記すると、121未満はマニフェストを拒否する）
- Firefox: バージョン 109以上（AMO、`strict_min_version`）。ショートカット用のイベントページは 121以上で起動する（それ未満は `service_worker` キーがあるとバックグラウンドが起動しない。コンテンツスクリプト自体は動く）
- YouTube: 最新のプレイヤーインターフェース

### セキュリティ

- 不要な権限は要求しない
- 外部ネットワーク通信は行わない
- ユーザーデータはローカルにのみ保存
- XSS対策を施す

### 信頼性

- ストレージ同期の競合を適切に処理
- エラー発生時は安全なデフォルト値を使用
- コンテンツスクリプトのクラッシュを防ぐ

## 技術的制約

### ブラウザ拡張の制約

- Manifest V3の制約を遵守
- コンテンツスクリプトは分離された世界で動作
- Service Workerはイベント駆動型で、長時間の実行は不可
- バックグラウンドでの永続的な監視は不可

### YouTubeページの制約

- YouTubeのDOM構造が変更される可能性がある
- プレイヤー要素は動的に生成される
- 外部CSSやJavaScriptを注入できない
