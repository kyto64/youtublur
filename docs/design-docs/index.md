## 設計アプローチ

### AI駆動開発

このプロジェクトは、OpenAIのHarness Engineeringの理念に則って設計されています。

- **漸進的開示**: 最小の安定したエントリーポイントから始め、必要に応じて文脈を広げる
- **知識のコード化**: すべての設計判断をリポジトリ内にバージョン管理
- **機械的強制**: ルールと原則をリンターやテストで自動強制
- **可視性の最大化**: エージェントが直接アクセスできるコンテキストを最大化

### コンポーネント設計

システムは独立したコンポーネントに分割され、明確な境界を持っています。

```
ユーザーインターフェース層 (ポップアップ)
    ↓
ビジネスロジック層 (src/content.ts → content.js)
    ↓
データ永続化層 (chrome.storage)
```

各層は疎結合であり、テスト可能に設計されています。
