# UI/UX ガイド

youyoutublur のユーザーインターフェースとユーザーエクスペリエンスに関するガイドです。

## デザイン原則

### コア原則

1. **シンプルさ**: 不要な要素を排除し、必要最小限の機能に絞る
2. **直感性**: ユーザーが迷わずに操作できるようにする
3. **即時性**: 操作から結果までの時間を最小限にする
4. **一貫性**: ブラウザ間で同じ体験を提供する

### 視覚的デザイン

#### カラーパレット

- **メインカラー**: `#FF0033` (赤)
  - ロゴ、アクセント要素に使用
  - ブランド認識の鍵となる色

- **背景色**:
  - ダークモード: `#1c1c1c`
  - ライトモード: `#ffffff`

- **表面色**:
  - ダークモード: `#2f2f2f`
  - ライトモード: `#f1f1f1`

- **テキスト**:
  - プライマリ: `#f1f1f1` (ダーク時) / `#0f0f0f` (ライト時)
  - セカンダリ: `#aaaaaa`

- **アクセント背景**: `rgba(255,0,51,0.12)`

#### タイポグラフィ

```css
font-family: "Roboto", "Segoe UI", "Yu Gothic UI", "Malgun Gothic", 
             "Microsoft YaHei", system-ui, sans-serif;
```

- 英語: Roboto（モダンで読みやすい）
- 日本語: Yu Gothic / Malgun Gothic（UI向けのゴシック体）
- 中国語: Microsoft YaHei（スクリーン向けの明朝体）

#### 影と奥行き

```css
/* ロゴの影 */
box-shadow: 0 4px 10px -3px rgba(255,0,51,0.5);

/* プレビューの枠 */
box-shadow: inset 0 0 0 1px rgba(255,255,255,0.04);
```

## ポップアップUI

### レイアウト仕様

```

  YouTube Background                         ← ヘッダー（40px）

  ┌────────────────────────────────────┐   ← モード選択（80px）
  │ ○ ブラー   ぼかしの背景            │
  │                                  │
  │ □ 単色   色を選んで背景を単一色に  │
  └────────────────────────────────────┘

  ┌────────────────────────────────────┐   ← プレビュー（60px）
  │  ███████████████████████████████  │
  │  █                               █  │
  │  █      [現在のモードのプレビュー]    │
  │  █                               █  │
  │  ███████████████████████████████  │
  └────────────────────────────────────┘

  [==========]                              ← リロードボタン（48px）
   再読み込み

```

### サイズ仕様

- **全体の幅**: 296px
- **高さ**: 可変（約250px）
- **角の丸み**: 10px（ラジオボタン）、6px（ロゴ）
- **余白**: 16px（左右）、10px（上下）

### インタラクション

#### モード選択

**初期状態**:
- 前回の設定が反映される
- プレビューは現在のモードの色で表示

**ホバー時**:
- 背景色が `var(--surface-hover)` に変化
- カーソルがポインターに変化
- トランジション: 140ms

**選択時**:
- 背景色が `var(--accent-soft)` に変化
- アイコンとドットがアクセント色に変化
- 即座にYouTubeページに反映

#### カラーピッカー

- 単色モード選択時に表示
- リアルタイムでプレビューを更新
- 選択した色は即座に保存・適用

#### リロードボタン

**通常時**:
- 背景: `var(--btn-bg)`
- テキスト: `var(--text)`

**ホバー時**:
- 背景: `var(--btn-hover)`

**アクティブ時**:
- 背景: `var(--accent)`
- テキスト: `#fff`

**リロード中**:
- 背景: `var(--accent)`（固定）
- テキスト: `#fff`（固定）
- 500ms後に元の状態に戻る

### アニメーション

#### トランジション

```css
/* 背景色の変化 */
transition: background 140ms ease;

/* プレビューの背景 */
transition: background 220ms ease;

/* アイコンの色 */
transition: color 140ms ease;
```

#### モード切替のアニメーション

- **フェードイン**: 220ms（背景色の変化）
- **即時反映**: モードアイコンの色変化
- **スムーズな移行**: プレビューの背景更新

## コンテンツスクリプトのUX

### パフォーマンスへの配慮

#### 動的描画間隔

コンテンツスクリプトはデバイスの性能に応じて描画間隔を調整します。

| 性能レベル | コア数 | メモリ(GB) | 描画間隔 |
|-----------|--------|-----------|----------|
| 高 | 5以上 | 8以上 | 1フレーム毎 |
| 中 | 3-4 | 4-8 | 2フレーム毎 |
| 低 | 2以下 | 2以下 | 3-4フレーム毎 |

#### FPS監視

- サンプルサイズ: 60フレーム
- 低速判定: 30 FPS未満
- 高速判定: 55 FPS以上
- 調整クールダウン: 300フレーム

### 視覚的フィードバック

#### モード切替時

1. ユーザーがポップアップでモードを選択
2. 設定が保存される（ストレージ）
3. コンテンツスクリプトにメッセージ送信
4. 即座に背景が更新される（50ms以内）

#### ブラーモード

- ブラー半径: 40px
- Firefox向け: 2段階の描画（ラスタライズ→ブラー）
- Chrome向け: 直接ブラー適用

#### 単色モード

- ダークテーマ: `#181818`
- ライトテーマ: `#f1f1f1`
- カスタム色: ユーザー選択の色

### エラーハンドリング

#### プレイヤー未検出時

1. 再試行スケジュールを設定
2. 指数関数的バックオフ（50ms → 2000ms）
3. 最大25回の試行
4. それでも検出できない場合は諦める

#### リロード失敗時

- ボタンが「リロード中」の状態を維持
- 500ms後に元の状態に戻る
- ユーザーにエラーを通知（コンソール）

## アクセシビリティ

### キーボードナビゲーション

- すべての操作がキーボードで可能
- `Tab` キーで要素間を移動
- `Enter` または `Space` で選択
- フォーカスの視覚的な表示

### 画面リーダー対応

```html
<!-- aria-label の使用 -->
<h3 id="popupHeading"></h3>

<!-- アイコンのアクセシビリティ -->
<svg aria-hidden="true">...</svg>
```

### 色のコントラスト

WCAG 2.1 AA基準を満たすように設計:

- テキストと背景のコントラスト比: 4.5:1以上
- 大きなテキスト: 3:1以上
- インタラクティブ要素: 視覚的なフィードバックあり

## レスポンシブデザイン

### ポップアップの制約

- 最小幅: 296px（固定）
- 高さ: コンテンツに合わせて可変
- スクロール: 発生しない（すべて表示）

### モバイル対応

ポップアップは小さな画面でも適切に表示:

- フォントサイズの相対指定（em/rem）
- タッチターゲットの最小サイズ（40px）
- 十分な余白（タッチ操作の誤爆防止）

## ユーザーテストの指標

### 定性的指標

1. **タスク完了率**: 95%以上
2. **エラー率**: 5%未満
3. **満足度**: 4/5以上（アンケート調査）

### 定量的指標

1. **初期表示時間**: 100ms以内
2. **モード切替時間**: 50ms以内
3. **設定保存時間**: 10ms以内
4. **メモリ使用量**: 5MB以内

## テストシナリオ

### 基本操作

1. 拡張機能アイコンをクリック
2. モードを「ブラー」に変更
3. YouTubeページの背景がブラーになることを確認
4. モードを「単色」に変更
5. 色を選択
6. 背景が選択した色になることを確認
7. リロードボタンをクリック
8. 設定が維持されていることを確認

### エッジケース

1. YouTubeページでないURLを開く
   - 期待: コンテンツスクリプトが動作しない

2. プレイヤーがまだ読み込まれていない
   - 期待: 再試行がスケジュールされる

3. ストレージがいっぱい
   - 期待: ローカルストレージにフォールバック

4. シークレットモード（Chrome）
   - 期待: ローカルストレージのみ使用
