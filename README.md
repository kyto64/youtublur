# YouTube Light Player Background

YouTubeのプレイヤー背景とヘッダーをライト（白）テーマに変更するChrome拡張機能です。

## 機能

- **プレイヤー背景**: 動画プレイヤー周辺の余白を白〜薄いグレー（#f1f1f1）に変更
- **ヘッダー**: ヘッダー全体をライトモードに強制（白背景・黒テキスト）
- **検索ボックス**: 検索ボックスとボタンのスタイルをライトモード用に調整
- **アイコン**: 虫眼鏡、マイク、その他のアイコンを黒色で表示（視認性向上）

## インストール方法

1. このフォルダをダウンロードまたはクローンする
2. Chromeで `chrome://extensions/` を開く
3. 右上の「デベロッパーモード」をONにする
4. 「パッケージ化されていない拡張機能を読み込む」をクリック
5. このプロジェクトのフォルダを選択する

## ファイル構成

```
youtube-white/
├── manifest.json   # 拡張機能の設定
├── style.css       # YouTube用のスタイル定義
└── README.md       # このファイル
```
